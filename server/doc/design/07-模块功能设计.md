## 7.1 数据汇聚与治理

### BR-01-01 多源数据采集与对接

| 属性 | 内容 |
| --- | --- |
| **优先级** | P0 |
| **关联 REQ** | REQ-01-01-01 ~ REQ-01-01-09 |
| **依赖组件** | IngestionService, StagingArea, SyncJobScheduler |

**设计目标**：统一接入院内 HIS/LIS/PACS/EMR 及院外平台，按 T+7/T+1/准实时策略同步至 Staging 层。

**功能分解**

| 子功能 | REQ | 设计要点 |
| --- | --- | --- |
| 协议适配器 | REQ-01-01-01 | 插件化 Adapter：HL7/FHIR/DICOM/JDBC/API |
| 临床数据采集 | REQ-01-01-02 | 映射至 staging_record.domain 分类采集 |
| 外部 ETL 汇聚 | REQ-01-01-03 | 外部 → Staging → 清洗，禁止直写 Published |
| 回顾性采集 | REQ-01-01-04 | 批量导入 + 元数据 + 规则引擎预审 |
| 多中心上传 | REQ-01-01-05 | `/integration/upload` + Excel 模板 |
| 同步调度 | REQ-01-01-06~09 | SyncJob.schedule_cron + 策略枚举 T7/T1/NEAR_RT |

**输入/输出**：输入=数据源配置、调度策略；输出=StagingBatch、SyncJob 日志

**界面要点**：数据源管理页、同步任务监控页、批次详情页

**验收设计点**：HIS/LIS 联调；三种周期可配；分中心上传解析成功
