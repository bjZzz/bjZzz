## 2. 目标架构（一期）

```mermaid
flowchart TB
  Web[Vue_Web] --> Nginx[Nginx]
  Nginx --> BootW[nanda-boot_写]
  Nginx --> BootR[nanda-boot_读_可选]

  BootW --> MySQL_M[(MySQL_主)]
  BootR --> MySQL_S[(MySQL_从_可选)]
  BootW --> Redis[(Redis_哨兵)]
  BootW --> MinIO[(MinIO)]
  BootW --> ES[(Elasticsearch)]
  BootW --> MQ[RabbitMQ]
  BootW --> FHIR[HAPI_FHIR]
  BootW -->|BFF| Sandbox[K8s_Sandbox_Pods]

  XXL[XXL-JOB] --> BootW
  MQ --> AssetRefresh[共病视图刷新]
  MQ --> IndexSync[ES_索引同步]
```

| 中间件 | 一期 |
| --- | --- |
| MySQL | 主库 + 可选读写分离/三库拆分（staging/core/system） |
| Redis | 会话/缓存/哨兵 |
| MinIO | 附件/导出/知识库 PDF/沙箱数据集 |
| Elasticsearch | 检索增强（与 MySQL idx 双写或切换） |
| RabbitMQ | 领域事件全量 |
| XXL-JOB | T+1、T+7、共病刷新、索引重建等 |
| Python Sandbox | K8s 每会话 Pod + Web IDE + 算法库 |
| HAPI FHIR | R4 读接口 + 回写 |

## 6. 风险与依赖

| 风险 | 缓解 |
| --- | --- |
| 全量中间件联调复杂 | 按 M1→M5 工作包递进；dev 环境 Docker Compose 一键起全栈 |

| 沙箱与 Java 双栈 | BFF 网关统一鉴权；内网 Token；K8s NetworkPolicy |
| 300 并发沙箱 | K8s HPA + 压测门禁 |
