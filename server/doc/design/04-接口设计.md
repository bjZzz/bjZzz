## 1. 统一约定

### 1.1 协议与格式

| 项 | 约定 |
| --- | --- |
| 协议 | HTTPS |
| 风格 | RESTful |
| 数据格式 | JSON（UTF-8） |
| API 版本 | URL 路径：`/api/v1/` |
| 时间格式 | ISO 8601：`2026-05-27T10:00:00+08:00` |
| 分页 | `page`（从 1 开始）、`size`（默认 20，最大 100） |
| 排序 | `sort=field,asc\|desc`，多字段逗号分隔 |

### 1.2 鉴权

| Header | 说明 |
| --- | --- |
| Authorization | `Bearer {access_token}` |
| X-Org-Id | 当前操作机构（可选，默认用户主机构） |
| X-Request-Id | 请求追踪 ID（建议客户端生成 UUID） |

### 1.3 统一响应结构

**成功**：

```json
{
  "code": 0,
  "message": "success",
  "data": { },
  "request_id": "uuid"
}
```

**分页**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [],
    "page": 1,
    "size": 20,
    "total": 100
  }
}
```

**错误**：

```json
{
  "code": 40001,
  "message": "参数校验失败",
  "errors": [{"field": "name", "reason": "不能为空"}],
  "request_id": "uuid"
}
```

### 1.4 HTTP 状态码

| HTTP | 场景 |
| --- | --- |
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 冲突（如重复合并 EMPI） |
| 422 | 业务规则校验失败 |
| 429 | 限流 |
| 500 | 服务器错误 |

### 1.5 业务错误码段

| 段 | 模块 |
| --- | --- |
| 10xxx | 平台/认证 |
| 20xxx | 采集/Staging |
| 30xxx | 治理/CRF/字典 |
| 40xxx | 资产/专病/共病 |
| 50xxx | 质控 |
| 60xxx | 检索/导出 |
| 70xxx | 科研/队列/随访 |
| 80xxx | 分析/沙箱 |
| 90xxx | 集成/外部 |
