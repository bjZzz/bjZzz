## 1. 文档说明

| 编号类型 | 格式 | 说明 |
| --- | --- | --- |
| 业务规则 | `RULE-{MOD}-{NNN}` | 可编码/可测试的若-则规则 |
| 模块流程 | `FLOW-{MOD}-{NNN}` | 模块内 flowchart |
| 跨模块流程 | `BP-01` ~ `BP-09` | 见 [FD-05](../design/05-业务流程设计.md) |

**模块代码**：PLT · ING · GOV · AST · RES · ANL · INT · SBX

**校验结论**：

1. 各模块 **§15 REQ 追溯矩阵** 与 [PRD 附录 A](../prd/00-PRD总览.md) 一一对应，合计 233 项无遗漏。
2. **§13 关联 REQ** 列对 P0/核心场景给出显式 REQ 编号；其余 REQ 通过规则表末「RULE-*-NNN~NNN 覆盖…」说明与 §15 范围合并追溯。
3. 测试用例 ID 建议：`TC-{REQ编号}` 映射 §15 实现列；规则级单测映射 `RULE-{MOD}-{NNN}`；端到端用例映射 `TC-BP-{NN}`。
