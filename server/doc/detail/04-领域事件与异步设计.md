## 4. 状态机总表

> **业务流程图**：各状态机的 Mermaid flowchart 细化见各模块 DD §14（[05-总览 §5](./05-模块业务规则与流程总览.md#5-模块流程索引)）；跨模块主流程见 [FD-05](../design/05-业务流程设计.md)。

### 4.1 StagingBatch

| 状态 | 下一状态 | 触发 |
| --- | --- | --- |
| RECEIVED | CLEANING | 自动 |
| CLEANING | MATCHED | 清洗完成 |
| MATCHED | READY_TO_PUBLISH | EMPI 完成 |
| READY_TO_PUBLISH | PUBLISHED | 发布成功 |
| * | REJECTED | 规则失败/人工拒绝 |

### 4.2 ExportTask

| 状态 | 下一状态 | 触发 |
| --- | --- | --- |
| DRAFT | PENDING_APPROVAL | 提交 |
| PENDING_APPROVAL | APPROVED / REJECTED | 审核 |
| APPROVED | PROCESSING | 开始导出 |
| PROCESSING | COMPLETED / FAILED | 完成/失败 |

### 4.3 ResearchProject

| 状态 | 下一状态 | 触发 |
| --- | --- | --- |
| DRAFT | APPROVED | 立项审批 |
| APPROVED | EXECUTING | 启动 |
| EXECUTING | CLOSING | 结题申请 |
| CLOSING | ARCHIVED | 归档 |

### 4.4 EmpiMatchCandidate

| 状态 | 下一状态 | 触发 |
| --- | --- | --- |
| PENDING | CONFIRMED | 人工确认合并 |
| PENDING | REJECTED | 人工拒绝 |
| CONFIRMED | — | 生成 empi_id |

### 4.5 CRF Response

| 状态 | 下一状态 | 触发 |
| --- | --- | --- |
| DRAFT | SUBMITTED | 提交 |
| SUBMITTED | APPROVED / REJECTED | 审核 |

### 4.6 AnalyticsJob（沙箱）

| 状态 | 下一状态 | 触发 |
| --- | --- | --- |
| QUEUED | RUNNING | Worker 领取 |
| RUNNING | SUCCEEDED / FAILED | 执行结束 |
| SUCCEEDED | EXPORT_PENDING | 需审核导出 |
