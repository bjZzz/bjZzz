## 2. 模块概述

提供 **CRF 表单引擎、字典与术语、清洗规则、入库发布、元数据血缘** 能力，将 Staging 数据治理为可发布的标准化资产。

---

## 3. 目标用户与角色

| 角色 | 场景 |
| --- | --- |
| 数据管理员 | 维护字典、清洗规则、入库规则 |
| 临床录入员 | CRF 录入、提交 |
| 科研项目负责人 | 设计/发布 CRF 版本 |
| 质控审核员 | 审核 CRF 提交 |

---

## 4. 范围定义

### 4.1 In Scope

- CRF 设计器、录入、量表计分、附件
- 四类清洗规则、术语库、四类字典、字段元数据
- 入库规则、字段映射、发布任务
- 元数据目录、版本比对、血缘图

### 4.2 Out of Scope

- EMPI 匹配（asset）
- 专病库查询展示（asset）
- 检索导出（analytics）

### 4.3 一期交付

本模块 **43 REQ 一期全量交付**，含：CRF、字典、清洗、入库发布、元数据血缘、规则模板库、字典联动事件。

## 6. 功能需求详述

### 6.1 BR-01-02 结构化专病数据录入（P0）

**用户故事**：作为**临床录入员**，我希望按专病 CRF 表单录入患者指标，以便结构化数据进入治理流程。

| 功能点 | REQ | 要点 |
| --- | --- | --- |
| 专病表单模板 | REQ-01-02-01 | 按 specialty_type 预置 |
| 三类专病+风险指标 | REQ-01-02-02~05 | dict_field_metadata 驱动 |
| 多题型 ≥10 种 | REQ-01-02-06 | schema_json.question.type |
| 附件 18 格式 | REQ-01-02-07 | MinIO + 预览 |
| 可视化设计器 | REQ-01-02-08 | 拖拽/点选 |
| 逻辑跳转 | REQ-01-02-09 | visibility_rule |
| 布局 | REQ-01-02-10 | single/two_column |
| 量表计分 | REQ-01-02-11 | CAT/mMRC 等 |

**验收**：10 种题型可用；计分正确；附件可预览。

### 6.2 BR-01-03 数据标准化与字典管理（P0）

| 功能点 | REQ | 要点 |
| --- | --- | --- |
| 清洗四类规则 | REQ-01-03-01~04 | 缺失/异常/重复/单位 |
| 质量概览/明细 | REQ-01-03-05~06 | 聚合+下钻 |
| 规则模板库 | REQ-01-03-07 | 复用 |
| 三类术语库 | REQ-01-03-08~10 | 按病种 |
| 跨标准映射 | REQ-01-03-11~13 | term_mapping |
| 归一化 | REQ-01-03-14~16 | term_synonym |
| 四类字典 | REQ-01-03-17~20 | 诊断/治疗/检验/症状 |
| 字段元数据 | REQ-01-03-21~23 | 联动 CRF/检索 |

**验收**：清洗生效；术语归一化抽样 ≥95%；字典变更联动 CRF。
