## 2. 模块概述

管理 **EMPI 主索引、三类专病库、共病库、医学知识库、质控与补录、患者全景与驾驶舱**，是平台核心数据资产层。

**数据原则**：仅消费 Governance 发布后的 Published 数据；`core_fields` + `extended_fields` JSON 动态字段模型。

---

## 3. 目标用户与角色

| 角色 | 场景 |
| --- | --- |
| 数据管理员 | EMPI 确认、专病库运维 |
| 质控审核员 | 抽样复核、月报 |
| 临床录入员 | 补录、双屏录入 |
| 科研人员 | 患者 360、驾驶舱概览 |
| 项目负责人 | 专病库运营指标 |

---

## 4. 范围定义

### 4.1 In Scope

- EMPI 精确/模糊匹配与人工确认
- 代谢/心脑血管/呼吸专病库
- 共病规则与物化视图
- 知识库（P1）
- 质控六维、补录闭环
- 驾驶舱、360、时间轴、溯源

### 4.2 Out of Scope

- 采集、清洗、CRF 设计（governance）
- 检索 DSL、导出审核（analytics）
- 外部回传 API 实现（integration，REQ-05-02-13）

### 4.3 一期交付

本模块 **57 REQ 一期全量交付**，含：EMPI、三类专病、共病库、知识库、驾驶舱/360/洞察/溯源、质控、补录。

## 6. 功能需求详述

### 6.1 EMPI（BR-01-04）

**用户故事**：作为**数据管理员**，我希望系统自动匹配患者并处理歧义候选，以便跨源数据归到同一 empi_id。

| 功能点 | REQ | 要点 |
| --- | --- | --- |
| 主索引体系 | REQ-01-04-01 | empi_master |
| 全景整合 | REQ-01-04-02 | timeline API |
| 多标识匹配 | REQ-01-04-03 | id_hash 精确优先 |
| 模糊匹配 | REQ-01-04-04 | 加权+人工确认 |
| 规则引擎 | REQ-01-04-05 | empi_rules 可配置 |

**验收**：测试集准确率 ≥99.8%；人工确认流程可用。

### 6.2 专病库（BR-05-02 ~ 04）

| 专病 | specialty_type | REQ | MVP |
| --- | --- | --- | --- |
| 代谢 | METABOLIC | REQ-05-02-01~03 | ● |
| 心脑血管 | CARDIO_CEREBROVASCULAR | REQ-05-02-04~06 | P1 |
| 呼吸 | RESPIRATORY | REQ-05-02-07~09 | P1 |

每库：7 类子域结构、概览统计、病种详情页（糖尿病/冠心病/慢阻肺示例）。

### 6.3 共病库（BR-05-05）

| 功能点 | REQ | 要点 |
| --- | --- | --- |
| 规则定义 | REQ-05-02-10 | expression_json |
| 动态视图 | REQ-05-02-11 | 物化视图+事件刷新 |
| 模板/回传 | REQ-05-02-12~13 | 回传 API 见 integration |
| 概览三类 | REQ-05-02-14~16 | 谱系/画像/质量 |
| 跨病种详情 | REQ-05-02-17~18 | 联邦查询+报告联动 |

**验收**：「糖尿病+冠心病」规则筛选正确。

### 6.4 驾驶舱与全景（BR-05-06，P1）

REQ-05-02-19~29：驾驶舱四模块、洞察四模块、360、时间轴、全链路溯源。

### 6.5 知识库（BR-05-01，P1）

REQ-05-01-01~06：指南管理、引用溯源、批量导入、分面检索、作者图谱、主题趋势。

### 6.6 质控（BR-05-09）

**流程 BP-03**：六维监控 → 抽样 → 差异比对 → 复核 → 月报。

| 功能点 | REQ |
| --- | --- |
| 六维仪表盘 | REQ-05-05-01~02 |
| 抽样与比对 | REQ-05-05-03~06 |
| 复核与月报 | REQ-05-05-07~09 |

### 6.7 补录（BR-05-10）

**流程 BP-02**：新增患者、双屏录入、缺失预警、权限隔离、痕迹追溯、双重核查。

| 功能点 | REQ |
| --- | --- |
| 新增/双屏/预警 | REQ-05-06-01~03 |
| 权限 | REQ-05-06-04~05 |
| 追溯/核查 | REQ-05-06-06~08 |
