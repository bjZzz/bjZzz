## 2. 模块概述

提供 **多维检索与导出、疾病风险评估、共病分析、统计工作台、业务分析场景、可视化仪表盘、评估报告**；复杂分析通过 **沙箱（Python）** 执行，遵守数据不出库原则。

**双引擎**：
- **平台内统计**：Java + Commons Math（描述统计、t 检验、回归等）
- **沙箱分析**：独立 Python 服务（因果、网络、自定义脚本）

---

## 3. 目标用户与角色

| 角色 | 场景 |
| --- | --- |
| 科研人员 | 检索、导出、统计、风险评分 |
| 项目负责人 | 审批导出、查看项目分析 |
| 数据管理员 | 配置检索索引（P1 ES） |

---

## 4. 范围定义

### 4.1 In Scope

- SearchQuery DSL、检索、提取任务、多格式导出
- 10 个风险评估模型 API
- 共病网络/因果分析（沙箱）
- 统计工作台 25+ 方法
- 业务分析 7 场景模板
- 仪表盘、PDF 报告（图表嵌入）
- 沙箱工作区、算法注册、任务队列

### 4.2 Out of Scope

- 外部 FHIR/回传 API 实现（[integration](./PRD-integration.md)）
- 专病库主数据维护（asset）

### 4.3 一期交付

本模块 **84 REQ 一期全量交付**（不分二期/三期），含：MySQL+ES 检索、导出/CDISC、10 风险模型、共病网络、PDF、统计工作台、业务分析、仪表盘、K8s 沙箱 Web IDE、个性化脚本。PRD 附录 P0/P1/P2 仅表示重要度。

## 6. 功能需求详述

### 6.1 检索（BR-10-01）

**用户故事**：作为**科研人员**，我希望用嵌套条件组合检索患者，以便构建研究队列。

| 类别 | REQ | 要点 |
| --- | --- | --- |
| 条件面板 | REQ-10-01-01~03 | 全场景、逻辑组合、跨病种 |
| 高级检索 | REQ-10-02-01~07 | 模糊/范围/精确/嵌套/范围限定/多类型/节点统计 |

**验收**：复杂嵌套正确；节点患者数准确。

### 6.2 导出（BR-10-02，BP-04）

| 类别 | REQ | 要点 |
| --- | --- | --- |
| 结果处理 | REQ-10-03-01~02 | 属性过滤、优化 |
| 提取任务 | REQ-10-04-01~03 | 创建/审核/查询 |
| 导出 | REQ-10-05-01~06 | 多格式、时间轴、CDISC、权限、审计、入组 |

**验收**：创建→审核→导出→审计全流程。

### 6.3 风险评估（BR-11-01）

10 个模型：PREVENT、ASCVD、Framingham、CHA₂DS₂-VASc、GOLD、CAT、BODE、FINDRISC、Charlson、Elixhauser（REQ-11-01-01~10）。

### 6.4 共病辨识（BR-11-02）

REQ-11-02-01~05：PSM/IV、可视化、Apriori/FP-Growth、网络图、分型标签（沙箱）。

### 6.5 沙箱与安全计算（BR-11-03）

| REQ | 要点 |
| --- | --- |
| REQ-11-03-01~04 | 算法进库、人进沙箱、部署、导入 |
| REQ-14-04-01~05 | 个人工作区、300 并发、不出库、防泄露、审核导出 |

**验收**：沙箱无法导出原始明细；压测 300 并发排队；水印生效。

### 6.6 报告（BR-13-01）

REQ-13-01-01~02：PDF 报告、动态图表嵌入。

### 6.7 统计工作台（BR-14-01）

REQ-14-01-01~25：描述、正态性、组间比较、相关、回归、生存、图表、独立数据集。

### 6.8 脚本分析（BR-14-02，P2）

REQ-14-01-26~28：Python 自定义、二次开发、安全管控。

### 6.9 业务分析（BR-14-03）

REQ-14-02-01~07：流行病学、资源利用、费用、健康指标、负担分析。

### 6.10 仪表盘（BR-14-04）

REQ-14-03-01~02：专业图表、拖拽仪表盘。
