## 2. 模块概述

提供全平台**机构、用户、认证授权、加密密钥、审计日志**能力，是所有业务模块的安全与组织边界基础。

**边界**：不包含业务数据采集、专病库、科研与分析逻辑；通过统一 `AuthContext` 向各模块提供用户、机构、权限上下文。

---

## 3. 目标用户与角色

| 角色 | 典型场景 |
| --- | --- |
| 系统管理员 | 维护机构树、用户账号、角色权限、审计查询 |
| 全体用户 | 登录、登出、查看个人信息与权限 |
| 数据管理员 | 配置数据权限范围（机构级） |

---

## 4. 范围定义

### 4.1 In Scope

- 机构 CRUD、层级树、机构关系
- 用户/账号管理、启用禁用、角色分配
- JWT 认证、Token 刷新、功能权限与数据权限校验
- L0~L3 加密分级、密钥管理、脱敏策略
- 全链路操作审计（只增不改）

### 4.2 Out of Scope

- 业务数据 CRUD（由各业务模块实现，统一走权限切面）
- CRF、专病库、检索等业务功能

### 4.3 一期交付

本模块 **16 REQ 一期全量交付**，含：RBAC、JWT、机构树、L0~L3 加密（含共病 L3 审批）、审计。外部 IAM/SSO 为接口预留，不单独分期。

## 6. 功能需求详述

### 6.1 BR-20-01 机构与用户管理

**用户故事**

- 作为**系统管理员**，我希望维护多级机构树，以便实现总中心与分中心的数据隔离。
- 作为**系统管理员**，我希望为用户分配角色与机构，以便控制其可访问的功能与数据范围。
- 作为**分中心协调员**，我只能看到本中心用户与数据（数据权限 DR-03）。

| 功能点 | REQ | 优先级 | 业务规则 |
| --- | --- | --- | --- |
| 机构信息维护 | REQ-20-01-01 | P0 | 机构编码唯一；删除前检查下级与用户 |
| 机构层级设置 | REQ-20-01-02 | P0 | 树形结构，禁止循环父级 |
| 机构关系配置 | REQ-20-01-03 | P0 | 支持协作/隶属等关系类型 |
| 用户信息管理 | REQ-20-02-01 | P0 | 关联主机构 `primary_org_id` |
| 账号创建与维护 | REQ-20-02-02 | P0 | 密码强度策略；支持冻结 |
| 用户角色分配 | REQ-20-02-03 | P0 | 多角色；权限取并集 |
| 多中心用户管理 | REQ-20-02-04 | P0 | 用户可绑定多个机构，请求头 `X-Org-Id` 切换上下文 |

**异常**：无权限返回 403；Token 过期返回 401；机构删除存在下级时返回 422。

### 6.2 BR-05-11 数据安全与合规

**用户故事**

- 作为**系统管理员**，我希望敏感字段自动加密存储，以便满足医疗数据合规要求。
- 作为**审计员**，我希望查询任意用户的访问记录，以便事后追溯。

| 功能点 | REQ | 优先级 | 业务规则 |
| --- | --- | --- | --- |
| 功能权限控制 | REQ-05-07-01 | P0 | RBAC，API 级 `@PreAuthorize` |
| 数据权限分配 | REQ-05-07-02 | P0 | 机构/项目/队列三维，规则 DR-01~06 |
| 通用身份加密 L1 | REQ-05-07-03 | P0 | AES-256：身份证、电话、住址 |
| 代谢/心脑血管/呼吸 L2 | REQ-05-07-04~06 | P0 | SM4 专科敏感字段 |
| 共病交叉 L3 | REQ-05-07-07 | P1 | 跨病种联合访问需审批 |
| 传输加密 | REQ-05-07-08 | P0 | HTTPS；外部对接双向认证 |
| 访问审计 | REQ-05-07-09 | P0 | `sys_audit_log` 只 INSERT |

## 14. 验收标准

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| AC-P-01 | 机构树 | 创建 3 级机构，树接口正确返回 |
| AC-P-02 | RBAC | 科研人员无法访问机构管理 API（403） |
| AC-P-03 | 数据权限 | 分中心用户仅见本中心数据 |
| AC-P-04 | 加密 | L1 字段库内密文，授权解密后明文 |
| AC-P-05 | 审计 | 登录、查询、导出均有审计记录且不可修改 |
| AC-P-06 | Token | 过期 Token 返回 401，Refresh 可换新 Token |
