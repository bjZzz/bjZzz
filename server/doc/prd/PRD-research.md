## 2. 模块概述

支撑科研项目全生命周期、科研队列构建与维护、随访管理及多项目协作，是临床科研组织与执行层。

---

## 3. 目标用户与角色

| 角色 | 场景 |
| --- | --- |
| 科研项目负责人 | 创建项目、设计研究、管理队列与权限 |
| 科研人员 | 查看项目进度、参与队列 |
| 临床录入员 | 执行随访任务、录入随访 CRF |
| 系统管理员 | 项目模板维护 |

---

## 4. 范围定义

### 4.1 In Scope

- 项目状态机、研究设计模板、一致性校验
- 队列纳排、动态维护、随机分组、成员管理
- 随访阶段、差异化表单、多渠道、任务追踪
- 多项目并行、节点提醒、进度统计

### 4.2 Out of Scope

- 检索条件构建（analytics，结果可 import-to-project）
- CRF 引擎本身（governance）
- 统计分析（analytics）

### 4.3 一期交付

本模块 **22 REQ 一期全量交付**，含：项目、队列、随访、多项目协作提醒与进度统计。
